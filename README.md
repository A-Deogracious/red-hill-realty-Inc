# Red Hill Realty Inc – Front-End Project

This is a front-end web application for **Red Hill Realty Inc**, a real estate company operating in Kampala, Uganda.  
The project is part of my Front-End Development exam at Cavendish University Uganda and demonstrates modern HTML, CSS, and JavaScript practices. [file:14]

## Project Goal

Provide a clean, responsive interface where users can:
- Browse homes for sale in Kampala
- See highlighted “Hot Deals”
- Request a free valuation for their property (“What’s Your Home Worth?”)
- Learn how to list their property with Red Hill Realty Inc
- Contact the agency for more information [file:14]

## Features

- Multi-page layout:
  - Home
  - Buy
  - What’s Your Home Worth
  - List With Us
  - Membership
  - Hot Deals
  - About
  - Contact
  - Legal pages (Privacy, Disclaimer)
- Desktop-first design with plans for responsive behaviour
- Reusable header and footer across pages
- Hero sections with Kampala imagery and clear call-to-action buttons
- Basic interactivity using JavaScript (navigation behaviour and UI enhancements) [file:14]

## Tech Stack

- HTML5 (semantic structure)
- CSS3 (layouts, typography, color system, responsive design)
- JavaScript (basic interactivity)
- Bootstrap grid (for layout support) [file:14]
